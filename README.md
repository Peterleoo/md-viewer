# MD Viewer & Editor (Windows)

A lightweight Electron + React application for viewing and editing Markdown files with multi‑tab support.

## Features
- Open multiple Markdown files in separate tabs
- Real‑time preview with syntax highlighting
- Save/auto‑save, export to HTML/PDF
- Light/Dark themes (future) and customizable CSS

## Development
```bash
npm install
npm run dev   # starts Electron + Vite dev server
```

## Build
```bash
npm run build   # bundles the renderer and packages the app for Windows
npm run package  # creates an installer (nsis)
```
